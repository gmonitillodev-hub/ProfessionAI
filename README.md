Repository di esercizi e appunti pratici Python.

## Contenuti

Il progetto contiene materiale didattico in formato notebook, organizzato nella cartella `python_training`.

- `Es2_Python_Concourrency.ipynb`
- `Es3_Python_Asyncio.ipynb`

## Come iniziare

1. Crea e attiva un virtual environment Python.
2. Installa Jupyter se non presente:
   ```bash
   pip install jupyter
   ```
3. Avvia Jupyter nella root del progetto:
   ```bash
   jupyter notebook
   ```
4. Apri i notebook nella cartella `python_training`.

## Note

- La cartella `.venv/` e i file `.idea/` sono artefatti locali dell'ambiente di sviluppo.
- Se vuoi, posso aggiungere anche una sezione con prerequisiti/versione Python consigliata e comandi standardizzati (`make`, script, ecc.).
